## Featured Projects

### Taskify

Aplicación web de gestión de tareas construida con
**React, TypeScript, Firebase y Firestore**.

Incluye autenticación con email y Google, persistencia y sincronización en
tiempo real, tablero Kanban, filtros, prioridades, seguimiento de progreso,
papelera e historial de actividad.

También incorpora servicios serverless autenticados y testing automatizado.

**Demo:** [Ver aplicación](https://takify-app-2026.vercel.app)  
**Repository:** [Ver código](https://github.com/JoaquinG-eng/Taskify-app)

---

### REST API Node

API REST desarrollada con **Node.js, Express y PostgreSQL**, aplicando
separación de responsabilidades entre rutas, controladores, servicios,
middlewares y acceso a datos.

Implementa autenticación JWT, autorización basada en roles, validaciones,
auditoría, soft delete, manejo centralizado de errores y documentación
mediante OpenAPI / Swagger.

Incluye pruebas automatizadas con **Vitest y Supertest** e integración
continua mediante GitHub Actions.

**Swagger:** [Ver documentación](https://rest-api-node-pbza.onrender.com/api-docs)  
**Repository:** [Ver código](https://github.com/JoaquinG-eng/Rest-Api-Node)

---

### ChatVerse AI

Aplicación conversacional integrada con **Gemini**, desarrollada con
JavaScript y Vite.

La integración con inteligencia artificial se ejecuta mediante funciones
serverless, evitando exponer credenciales sensibles en el frontend.

Incluye persistencia de conversaciones, control de contexto, manejo de tokens,
accesibilidad, navegación SPA y testing automatizado.

**Demo:** [Ver aplicación](https://chatverse-ia.vercel.app)  
**Repository:** [Ver código](https://github.com/JoaquinG-eng/Chatverse-ai)

---

### GitHub AI Agent | MCP Server

Servidor **Model Context Protocol** desarrollado con **Node.js y TypeScript**
para conectar modelos de lenguaje con la API de GitHub.

Expone herramientas que permiten consultar repositorios, commits e issues,
además de ejecutar acciones como crear branches, commits, issues y pull
requests mediante lenguaje natural.

El proyecto incorpora validación de inputs, manejo estructurado de errores,
retry con exponential backoff y testing con Vitest.

**Repository:** [Ver código](https://github.com/JoaquinG-eng/JoaquinG-eng-ProyectoM5-JoaquinGonzalezFT73)
